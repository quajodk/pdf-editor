### Technical Implementation Notes

**PDF Coordinate System:**
- Canvas: Origin at top-left, Y increases downward
- PDF: Origin at bottom-left, Y increases upward
- Conversion: `pdfY = pageHeight - canvasY - height`

**pdf-lib Rendering:**
- Text: `page.drawText()` with font embedding
- Rectangles: `page.drawRectangle()` with border
- Ellipses: `page.drawEllipse()` with center and radii
- Lines: `page.drawLine()` with start/end points
- Highlights: Rectangles with opacity
- Drawings: Series of connected `drawLine()` calls

**Limitations:**
- pdf-lib doesn't support arrow heads (drawn as regular lines)
- pdf-lib doesn't support smooth curves (pen strokes are segmented)
- Font embedding not yet implemented (uses default fonts)

**Double-Click Edit Flow:**
```
1. User switches to Select tool
2. User double-clicks on text annotation
3. handleDoubleClick finds annotation at click position
4. Sets editingTextId and opens input with existing text
5. User modifies text and presses Enter
6. handleTextSubmit updates annotation (not creates new)
7. editingTextId cleared, normal text display restored
```

**Key Code Changes:**
- `editingTextId` state: Tracks which annotation is being edited
- `handleDoubleClick`: Detects double-click, finds text, opens editor
- `handleTextSubmit`: If editingTextId set → update, else → create
- Pointer events: Changed from blocking to allowing in select mode
- Text rendering: Skip annotation with `id === editingTextId`
